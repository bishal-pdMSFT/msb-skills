# XLSX Skill

This skill creates, edits, analyzes, and recalculates spreadsheet files
(.xlsx, .xlsm, .csv, .tsv).

## Scope

This skill applies whenever the user asks you to: (1) create new spreadsheets
with formulas or formatting, (2) read or analyze spreadsheet data,
(3) modify existing spreadsheets while preserving formulas and templates,
(4) produce financial models with industry-standard color coding and number
formats, or (5) recalculate workbook formulas after programmatic edits.

## Workflow reference

The detailed workflow — formula construction rules, color-coding conventions,
environment setup, LibreOffice invocation patterns, and the formula
verification checklist — is documented in the companion file
`xlsx_workflow_reference.pdf` alongside this `SKILL.md`. Consult it for the concrete
procedures referenced above.
