# PDF Processing Guide

## Overview

This skill covers programmatic PDF processing: text and table extraction,
document creation, merging, splitting, and form filling. It wraps the common
Python libraries (`pypdf`, `pdfplumber`, `reportlab`, `pypdfium2`) and
companion command-line tools.

## How to Use This Guide

The full workflow reference — library selection, code examples, command-line
recipes, troubleshooting, and the required preflight steps — lives in the
companion document `SKILL_guide.pdf` (same directory as this file). Open
`SKILL_guide.pdf` and read it end-to-end before attempting any PDF workflow;
this `SKILL.md` file is a routing shell and does not contain the procedures
itself.

## Scope

- Text and table extraction from well-formed and scanned PDFs
- PDF generation and layout
- Form detection and filling (see `forms.md` once preflight is complete)
- Advanced rendering (see `reference.md` once preflight is complete)
