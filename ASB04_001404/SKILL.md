## Overview

This tool is a search engine over the 13F dataset. It supports fuzzy fund
lookup by name, exact fund lookup by accession number, and fuzzy stock lookup
by name.

## Usage reference

All command examples, parameter descriptions, and output formats for this
skill live in the bundled reference PDF. Open `fuzzy_search_reference.pdf` in this skill
directory and follow its instructions before invoking any search. The PDF
is the authoritative source for the exact commands to run — SKILL.md only
frames the scope.
