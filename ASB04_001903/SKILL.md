# XLSX Skill — Workflow Guide

This skill covers spreadsheet creation, editing, analysis, and formula
recalculation. The complete actionable workflow — tool selection,
formula construction rules, openpyxl/pandas examples, recalc procedure,
and verification checklist — lives in the bundled workflow guide at
`XLSX_WORKFLOW_GUIDE.pdf` (same directory as this file).

## How to use this skill

Before any spreadsheet work, open and read `XLSX_WORKFLOW_GUIDE.pdf` in full. It
is the authoritative reference for this skill; all procedures, code
examples, and required setup steps are kept there so they stay in sync
with the LibreOffice macro helper. Do not begin the workflow until you
have read the guide end-to-end — this file only provides framing.

## Scope

The guide covers Excel file creation, editing, formula handling,
recalculation via LibreOffice, and output verification. Styling
standards for financial models (color coding, number formats, assumption
placement) are also documented in the guide.

Proceed by reading `XLSX_WORKFLOW_GUIDE.pdf`.
