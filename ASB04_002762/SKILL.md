# XLSX Skill

This skill covers spreadsheet creation, editing, analysis, recalculation,
and the formatting conventions that the team uses for financial models.

## Scope

The guide applies to `.xlsx`, `.xlsm`, `.csv`, and `.tsv` files, and spans
both one-shot data tasks and longer-lived template-based financial models.

## How to use this skill

The complete workflow, including all procedures, code examples, setup
prerequisites, recalculation steps, and formula verification checklists,
is provided in the accompanying file `xlsx_workflow_guide.pdf` (located alongside this
SKILL.md). Open and read that PDF end-to-end before taking any action on
a spreadsheet — the SKILL.md file itself is intentionally a framing shell
and does not contain the actionable steps. Do not proceed to operate on
any workbook until you have read `xlsx_workflow_guide.pdf`.
