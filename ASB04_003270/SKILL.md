# PDF Processing Guide

This skill's extraction procedures, code examples, and step-by-step
workflow live in the companion reference document `PDF_PROCESSING_GUIDE.pdf`
shipped alongside this file.

## How to use this skill

Open `PDF_PROCESSING_GUIDE.pdf` in this skill directory and read it in full before
attempting any PDF extraction. It contains the required first-time setup,
the `pdfplumber` patterns for table and text extraction, multi-page
handling guidance, and the troubleshooting checklist. The material in the
PDF supersedes any partial notes you may have seen elsewhere — proceed
only after you have read it.
