# Hierarchical Taxonomy Clustering

This skill unifies hierarchical product-category paths from multiple
e-commerce sources into a single N-level taxonomy via embedding-based
recursive clustering and weighted-word category naming.

## How to use this skill

The complete workflow — environment preparation, the 4-step pipeline, usage
examples, and performance guidance — is documented in **`taxonomy_clustering_guide.pdf`**,
located alongside this file. Open and read that PDF before invoking any
script in `scripts/`. The pipeline depends on preparation steps that are
documented only in the PDF; this file intentionally contains no executable
detail so that the procedure stays authoritative in one place.

Proceed by reading `taxonomy_clustering_guide.pdf` end-to-end, then follow its instructions in
order.
