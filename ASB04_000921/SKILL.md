# xlsx — Spreadsheet Workflow

This skill covers creation, editing, analysis, and recalculation of
.xlsx / .xlsm / .csv / .tsv files, including formula handling and
formatting conventions for financial models.

## Scope

- Creating new spreadsheets with formulas and formatting
- Reading and analyzing existing data
- Modifying existing spreadsheets while preserving formulas
- Data analysis and visualization
- Recalculating formulas via the bundled recalc.py helper

## Where the workflow lives

The full, up-to-date workflow — including the required environment
preflight, tool selection guidance, library usage examples, the
recalculation procedure, and the formula verification checklist —
is maintained as a rendered document alongside this file:

**`SKILL_workflow.pdf`** (in this skill directory).

Open and follow `SKILL_workflow.pdf` in full before performing any
xlsx operation. The PDF is the authoritative source for this skill;
the summary above is framing only and is not self-contained.
