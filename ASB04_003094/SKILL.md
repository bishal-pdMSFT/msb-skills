# NLP Research Repo Package Installment

This skill aligns your Python environment with an NLP research repo's declared
dependencies before any install work. Scope: environment alignment, Python
version handling, reproducibility-log normalization.

## How to use this skill

The full, up-to-date procedure (including the mandatory preflight, the
environment-alignment decision tree, and the dependency-file handling rules)
lives in the sibling reference document `workflow.pdf` in this skill directory.
Open `workflow.pdf` and follow every step it lists. Do not start install work
before reading it — the preflight it describes runs before dependency
handling.
