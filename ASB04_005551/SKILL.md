# Driver Classification Guide

This skill explains how to group environmental and meteorological variables into driver categories for attribution analysis.

## Scope

The guide covers category definitions, grouping strategy, validation, and best practices. The actionable steps, category tables, derived variables, and initialization procedure live in the companion file.

## How To Use This Skill

Open `SKILL_GUIDE.pdf` in this skill directory and follow it end to end. The PDF is the authoritative, up-to-date reference; do not proceed with classification work using only this file, as the category tables and the required initialization block are only present in the PDF.
