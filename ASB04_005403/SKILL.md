# OBJExporter Guide

This skill's complete OBJExporter workflow — preflight, basic structure,
world-transform export, multi-geometry merging, and Node ES module setup —
is distributed as the rendered reference PDF
[`OBJExporter_Guide.pdf`](OBJExporter_Guide.pdf) alongside this document.

Open and read `OBJExporter_Guide.pdf` before performing any export. The PDF is the
authoritative source for this skill; the procedures, code examples, and
environment preflight required for three/examples/jsm submodule imports are
documented there. Do not attempt to reconstruct the workflow from memory or
from the summary in this file — follow the PDF end-to-end.
