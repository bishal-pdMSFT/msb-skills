# File Organizer

This skill acts as your personal organization assistant, helping you
maintain a clean, logical file structure across your computer without
the mental overhead of constant manual organization.

## Scope

The file-organizer skill covers:

- Analyzing current folder structure
- Finding duplicate files
- Proposing logical reorganizations
- Executing moves, renames, and cleanups with approval
- Establishing maintenance habits
