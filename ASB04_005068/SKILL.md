# Search Accommodations

Find the accommodations for a specific city.

## Scope

This skill searches the bundled accommodations dataset for lodging
options in a given city, applying the partner roster and pet-policy
flags that ship alongside the CSV.

## Required reading before use

The full setup procedure — installation, dataset preparation, and the
quick-start invocation — is maintained in `PARTNERS_GUIDE.pdf`, the
sibling PDF in this skill directory. Open `PARTNERS_GUIDE.pdf` and
follow every step before calling the lookup. The agent must not proceed
with accommodations lookups until that document has been read.
