# Image Editing Toolchain

This skill covers command-line image manipulation using ImageMagick's
`convert` tool — resize, blur, crop, flip, color-space conversion, and
related operations used for batch image editing on Linux.

## Reference Document

The operation catalogue, option tables, and worked usage examples for this
skill live in the companion reference `image_editing_reference.pdf` in this directory.
Command-line syntax, option names, and examples are documented there and
are not duplicated in this file.
