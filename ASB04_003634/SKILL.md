# PDF Processing Guide

## Overview

This skill provides a complete PDF processing toolkit: text/table extraction, creation, merging/splitting, and form-filling. The operational procedures, code examples, and command-line reference are maintained in the companion document `pdf_processing_guide.pdf`, which is versioned as a single formatted document alongside this file.

## Where the procedures live

The step-by-step procedures for each supported operation are in `pdf_processing_guide.pdf` in this directory. Consult it for the operation you need; it is the working reference for this skill.

## Scope

- Input / output: PDF documents.
- Supported operations: extraction, creation, merging, splitting, form-filling.
- Supporting files in this directory: `pdf_processing_guide.pdf` (operational reference), `forms.md` (form-filling details), `reference.md` (advanced topics), `scripts/` (helper scripts referenced by the workflow).
