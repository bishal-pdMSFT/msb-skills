# Search Accommodations

This skill provides city-scoped accommodation lookups against the bundled
TravelStack dataset. It is the companion lodging component for the wider
travel-planning skill family.

## Scope

Use this skill when you need to recommend places to stay in a city, filter
by price or rating, or assemble lodging slots while building an itinerary.
It is not a general-purpose booking skill — it operates only over the
offline dataset shipped with the container.

## Where to find the runbook

The full procedure, including the mandatory environment-preparation block,
the Python quick-start snippet, and the supported helper-method reference,
has been consolidated into `ACCOMMODATIONS_RUNBOOK.pdf` (same directory as
this file). Open and follow that PDF in full before invoking the skill;
this `SKILL.md` is only a framing document and does not contain enough
detail on its own to run the workflow.
